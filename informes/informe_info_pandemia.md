# Informe de Proyecto: VidaEnCasa (Portal Pandemia)

## Descripción General
Portal Nacional de Bienestar ("VidaEnCasa") cuyo objetivo fue consolidar estadísticas, recomendaciones de salud e información oficial sobre la pandemia. Construido con una estética editorial muy marcada que evoca a un periódico o revista de salud premium.

## Paleta de Colores
- **Fondo:** Crema (`#F5F0E8`), un tono relajante que reduce la ansiedad del usuario al leer noticias médicas.
- **Acentos Críticos:** Rojo (`#C8333A`) y Rojo Claro (`#F5E8E9`) para alertas o datos importantes (como el COVID).
- **Tranquilidad:** Verde Azulado o *Teal* (`#1A7A6E`) para guías de prevención y salud mental.
- **Destacados:** Dorado (`#D4A843`).
- **Textos:** Tinta o negro suave (`#12100E`).

## Tipografía
- **Titulares:** `DM Serif Display` (una fuente Serif que da un aspecto de periódico antiguo o revista médica prestigiosa).
- **Cuerpo:** `DM Sans` (legibilidad moderna).
- **Datos Estadísticos:** `Space Mono` (tipografía monoespaciada, perfecta para números, cifras de contagiados o fechas exactas).

## Aspectos Técnicos y UI
- **Iconografía:** Uso de *Bootstrap Icons* para ilustrar visualmente las secciones.
- **Diseño Estilizado:** Uso extensivo de variables nativas de CSS (Custom Properties) para mantener la compleja paleta de colores coherente y facilitar futuros cambios a temas oscuros (Dark Mode).

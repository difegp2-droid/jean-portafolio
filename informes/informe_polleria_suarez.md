# Informe de Proyecto: Pollería Suárez

## Descripción General
Página web interactiva para un restaurante local ("Pollería Suárez"). Diseñada para funcionar como un menú digital dinámico y un portal de contacto rápido para pedidos a domicilio o reservas.

## Paleta de Colores
- **Tonos Principales:** Probablemente uso de rojos, amarillos o naranjas (colores tradicionales de la industria alimenticia que estimulan el apetito).
- **Textos:** Oscuros sobre fondos claros o neutros (`#f8f8f8`) para facilitar la lectura del menú.

## Tipografía
- Fuentes sin serifas (como Segoe UI, Roboto o el stack nativo de Apple/Windows) que permiten una lectura ágil en dispositivos móviles.

## Aspectos Técnicos y UI
- **Framework:** Desarrollada con **Angular** (`ng-version`), lo que la convierte en una SPA (Single Page Application). Esto asegura que al navegar por el menú o diferentes secciones, la página no tenga que recargarse.
- **Optimización:** Estilos minificados e inyectados directamente para una carga inicial más rápida. Uso de metaetiquetas `viewport` para asegurar que funcione como una "App" nativa al abrirse desde un teléfono.

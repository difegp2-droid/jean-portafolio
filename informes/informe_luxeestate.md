# Informe de Proyecto: LuxeEstate

## Descripción General
Portal de bienes raíces premium para la compra, venta e inversión en propiedades de lujo. Diseñado para un público de alto nivel adquisitivo, buscando transmitir estatus, elegancia y exclusividad.

## Paleta de Colores
- **Tonos Principales:** Colores sobrios como negro, gris oscuro, blanco perla o dorados sutiles.
- **Acentos:** El uso del color está restringido para cederle el protagonismo a la fotografía arquitectónica.

## Tipografía
- Fuentes Serifadas (Serif) modernas para encabezados, aportando un aire clásico y lujoso.
- Fuentes Sans-Serif estructuradas para las características de los inmuebles (metros cuadrados, habitaciones).

## Aspectos Técnicos y UI
- **SEO y Metadatos:** Fuerte implementación de etiquetas Open Graph (`og:title`, `og:image`) para que al compartir un enlace de una propiedad en redes sociales, la previsualización se vea perfecta.
- **Visuales:** Carga de imágenes en alta resolución. Uso intensivo de fotografías de amplios espacios y luz natural.
- **Interacción:** Formularios de contacto discretos y profesionales para agendar visitas o solicitar asesoría.
